# lab_3: FX Kelly基準 注文リスク管理ツール

このディレクトリは、FX資金管理記事に対応する教育用ツール、記事骨子、計算仕様をまとめた実験ラボである。

記事の目的は、Kelly基準を「勝てる注文数量を出す公式」としてではなく、1回のトレードで許容できる最大損失額を求め、その金額を注文数量・損切り幅・1pip価値・証拠金条件に落とし込むことである。

このラボは完成した売買戦略や投資助言ではない。勝率、平均利益、平均損失、スプレッド、スリッページ、STOP超過、証拠金使用率を入力し、注文前にリスクが過大でないかを確認するための教育用チェックツールである。

## 実験の位置づけ

この実験では、Kelly基準をFXの注文前チェックに変換するため、以下の順に整理している。

1. 勝率、平均利益、平均損失からFull Kelly係数を計算する
2. スプレッドと通常スリッページを取引コストとして控除する
3. Kelly倍率と1回あたりリスク上限から採用リスク率を決める
4. 口座資金から最大許容損失額を計算する
5. 注文数量から、チャート上で許容できる損切り幅を逆算する
6. 損切り幅から、Kelly上の理論最大注文数量を逆算する
7. 証拠金使用率上限、証拠金上のハード上限、最低注文数量、注文数量刻みを反映する
8. 連敗、Monte Carlo、Kelly倍率別比較で破産耐久性を確認する

記事本文に対応する正本ツールは `kelly_fx_position_size_tool.html` である。記事骨子は `fx_kelly_article_outline_with_tools.md` にまとめている。

## ツールの構成

`kelly_fx_position_size_tool.html` は2つのタブを持つ。

| タブ | 役割 |
|---|---|
| 注文リスク計算 | Kelly基準から最大許容損失額を出し、注文数量・損切り幅・証拠金条件に変換する |
| 破産耐久性シミュレーター | 連敗、Monte Carlo破産確率、Kelly倍率別比較、最大DD、最終資産分布を確認する |

注文リスク計算タブには、さらに2つの計算モードがある。

| モード | 目的 |
|---|---|
| 注文数量 -> 許容損切りpips | 予定している注文数量で、チャート上どこまで逆行を許容できるかを見る |
| 損切りpips -> 最大注文数量 | 先に損切り幅を決め、その損切り幅で許容できる最大注文数量を逆算する |

## 入力条件

主な入力項目は以下である。

| 入力 | 用途 |
|---|---|
| 口座資金 | 最大許容損失額、証拠金余力、シミュレーション初期資金に使う |
| 勝率 | Kelly係数とMonte Carlo勝敗確率に使う |
| 平均利益pips | Kelly計算とシミュレーション利益幅に使う |
| 平均損失pips | Kelly計算とシミュレーション損失幅に使う |
| 想定スプレッド | Kelly計算上の取引コストに使う |
| 通常スリッページ | Kelly計算上の取引コストに使う |
| STOP超過見積り | 損切り幅や最大注文数量の逆算に加算する |
| Kelly倍率 | Full Kellyをどの程度落として使うかを決める |
| 1回あたりリスク上限 | Kelly計算値が大きすぎる場合の上限 |
| 最低注文数量 | その条件で注文可能かを判定する下限 |
| 注文数量刻み | 最大注文数量を実際の発注単位に丸めるための刻み |
| 注文予定数量 | 注文数量から許容損切りpipsを逆算する場合に使う |
| 想定損切り幅 | 損切りpipsから最大注文数量を逆算する場合に使う |
| 決済通貨、現在レート、決済通貨->円レート | 1pip価値、建玉金額、必要証拠金の計算に使う |
| 口座種別、レバレッジ | 国内個人口座25倍制限、証拠金上限計算に使う |
| 証拠金使用率上限 | 口座資金の何%まで必要証拠金に使うかを制限する |

このツールでは、表示上の「注文数量」はブローカーごとのロット表記ではなく、実際の通貨数量として扱う。たとえば `20,000` と入力した場合は、20,000通貨を意味する。

## 計算式

Kelly計算では、通常取引コストとSTOP超過を分けて扱う。

```text
取引コスト = スプレッド + 通常スリッページ
実効平均利益 = 平均利益 - 取引コスト
実効平均損失 = 平均損失 + 取引コスト
損益比 b = 実効平均利益 ÷ 実効平均損失
Full Kelly係数 f* = (b × p - q) / b
採用リスク率 = min(Full Kelly係数 × Kelly倍率, リスク上限)
最大許容損失額 = 口座資金 × 採用リスク率
```

注文数量から許容損切りpipsを逆算する場合は、次のように計算する。

```text
1通貨あたり1pip価値 = 1万通貨あたり1pip価値 ÷ 10,000
1pip損失額 = 注文数量 × 1通貨あたり1pip価値
実効損失幅上限 = 最大許容損失額 ÷ 1pip損失額
チャート上の損切り目安 = max(0, 実効損失幅上限 - STOP超過見積り)
```

損切りpipsから最大注文数量を逆算する場合は、次のように計算する。

```text
Kelly上の理論最大数量
= 最大許容損失額 ÷ ((想定損切り幅 + STOP超過見積り) × 1通貨あたり1pip価値)

証拠金バッファ込み最大数量
= 口座資金 × 証拠金使用率上限 × レバレッジ ÷ 建玉単価円

証拠金上のハード上限
= 口座資金 × レバレッジ ÷ 建玉単価円

採用最大注文数量
= min(Kelly上の理論最大数量, 証拠金バッファ込み最大数量) を注文数量刻みに丸めた数量
```

証拠金上のハード上限は、必要証拠金から見た理論上限であり、推奨数量ではない。実務ではKelly上限だけでなく、証拠金使用率上限も確認する。

## デフォルト条件の読み方

主なデフォルト値は以下である。

| 項目 | 既定値 |
|---|---:|
| 口座資金 | 1,000,000円 |
| 勝率 | 55% |
| 平均利益 / 平均損失 | 30 pips / 30 pips |
| 想定スプレッド | 0.2 pips |
| 通常スリッページ | 0.1 pips |
| STOP超過見積り | 0.3 pips |
| Kelly倍率 | Half Kelly |
| 1回あたりリスク上限 | 2% |
| 注文予定数量 | 10,000通貨 |
| 最低注文数量 | 100通貨 |
| 注文数量刻み | 100通貨 |
| 口座種別 | 国内個人口座 |
| レバレッジ | 5倍 |
| 証拠金使用率上限 | 50% |

この条件では、採用リスク率は2%上限に制限され、最大許容損失額は20,000円になる。USDJPY 155円、10,000通貨、1pip損失100円の前提では、実効損失幅上限は約200pips、STOP超過見積り0.3pipsを控除したチャート上の損切り目安は約199.7pipsとなる。

## 破産耐久性シミュレーターの注意点

シミュレーターは、注文リスク計算タブの入力条件を引き継ぐ。ただし、負けトレード幅には2つの扱いがある。

| 選択肢 | 内容 |
|---|---|
| Kelly計算の実効平均損失pipsを使う | 過去の平均損失を前提に、戦略全体の破産耐久性を見る |
| 今回の損切り幅 + STOP超過見積りを使う | 逆算モードで入力した今回の損切り幅を、シミュレーションの負け幅として使う |

「30pips損切りなら何通貨までか」を逆算した場合でも、シミュレーターが必ず30pips損失で動くわけではない。今回の損切り幅を使いたい場合は、シミュレーター側で明示的に選択する。

## 記事との対応

記事骨子は `fx_kelly_article_outline_with_tools.md` にある。

記事で強調するべき点は、次の整理である。

```text
Kelly基準が直接出すのは、損切りpipsでも注文数量でもない。
Kelly基準が出すのは、口座資金に対する理論上のリスク許容率である。

FX実務では、それを
最大許容損失額
=> 注文数量
=> 1pip損失額
=> 損切り幅
=> 証拠金使用率
へ変換して確認する必要がある。
```

記事では、Kelly基準を利益最大化の道具としてではなく、過大ポジションを避けて破産リスクを下げるためのリスク可視化ツールとして扱う。

## 解釈上の注意点

このツールの計算結果は、安全保証ではない。

- Kelly係数は、勝率・平均利益・平均損失の推定が正しいことを前提にしている。
- 平均利益・平均損失は、同じ通貨ペア、同じ戦略条件、同じような取引数量で集計したpipsを使う必要がある。
- スプレッド、スリッページ、STOP超過、約定拒否、窓開け、流動性低下は、実際には入力値より悪化する可能性がある。
- 国内個人口座では25倍以下を前提にする。法人店頭FXでは通貨ペアごとに証拠金率が異なり、少なくとも週1回見直されるため、FX会社が提示する必要証拠金率を確認する。
- 証拠金上のハード上限は推奨数量ではない。必要証拠金が口座資金の大部分を占める注文は、資金管理上危険である。
- Monte Carloはランダムな勝敗順序を可視化する簡易モデルであり、急変時の実損失を完全に再現するものではない。

このラボは、FXの資金管理を「雰囲気」ではなく、許容損失額、注文数量、損切り幅、pip価値、証拠金使用率に分解して確認するための教育用実験である。
