## 1. 目的

Phase 1 の目的は、BTC / ETH / SOL を同じ暗号資産として一括りにせず、4時間足リターン分布の性格差を確認することである。

この段階では、まだ「急落後に買えるか」は判断しない。次の Phase 2 で急落・急騰後のイベントスタディを行う前に、各銘柄のボラティリティ、テール、極端値、歪度を把握する。

## 2. 分析条件

| 項目 | 内容 |
|---|---|
| 対象 | BTCUSDT / ETHUSDT / SOLUSDT |
| 足種 | 240分足 |
| 共通期間 | `2020-08-11 04:00` から `2026-05-29 12:00` |
| リターン定義 | `log(close_t / close_{t-1}) * 100` |
| 有効リターン数 | 各銘柄 `12702` |
| 欠損処理 | 4時間の時刻飛びをまたぐリターンは除外 |

Phase 0 で、共通期間内には全銘柄で `2023-02-06 04:00 -> 2023-02-06 12:00` の1本欠損が確認された。そのため Phase 1 では、このギャップをまたぐリターンを各銘柄1件ずつ除外している。

| 銘柄 | 平均4Hリターン | 中央値 | 標準偏差 | 歪度 | 超過尖度 | 最小 | 最大 |

| ETHUSDT | `+0.0127%` | `+0.0272%` | `1.6416%` | `-0.3108` | `6.8850` | `-15.0157%` | `+11.4179%` |
| SOLUSDT | `+0.0262%` | `0.0000%` | `2.5294%` | `+0.2355` | `10.5025` | `-31.2571%` | `+26.7776%` |

## 4. 読み取り

### 4.1 BTCUSDT

BTC は3銘柄の中では最も安定している。

標準偏差は `1.2438%` と最小で、下位5%の4時間リターンも `-1.8988%` と、ETH や SOL より浅い。歪度は `-0.1593` で、やや下方向に傾いているが、ETH ほど強くはない。

ただし、BTC も通常の正規分布に近いわけではない。超過尖度は `8.7655` と高く、最大下落 `-11.1249%`、最大上昇 `+13.7577%` のような極端な4時間足リターンが存在する。

記事での使い方:

- BTC は暗号資産の基準軸として扱いやすい。
- 3銘柄の中では最も低ボラだが、それでもファットテールは明確に存在する。
- 「BTCですら正規分布前提では危ない」という導入に使える。

### 4.2 ETHUSDT

ETH は BTC より明確にボラティリティが高く、下方向の歪みも強い。

標準偏差は `1.6416%` で BTC を上回る。歪度は `-0.3108` と3銘柄で最もマイナス方向に傾いており、最大下落も `-15.0157%` と大きい。

下位5%は `-2.5347%`、下位1%は `-5.0589%` であり、BTC と同じ「急落」という言葉を使っても、ETH ではより大きい価格変化を意味する。

記事での使い方:

- ETH は BTC より下側ショックが強い銘柄として説明できる。
- 急落後ロング候補を調べる価値はあるが、「落ちたら戻る」と単純化するには危険である。
- Phase 2 では、急落後の平均回帰と下落継続のどちらが強いかを慎重に見る必要がある。

### 4.3 SOLUSDT

SOL は BTC / ETH と同列に扱うには危険な高ボラ・厚いテール銘柄である。

標準偏差は `2.5294%` で、BTC の約2倍である。最大下落は `-31.2571%`、最大上昇は `+26.7776%` と極端で、超過尖度も `10.5025` と最大である。

歪度は `+0.2355` とプラスだが、これは「安全」という意味ではない。上方向の外れ値も大きい一方で、下方向にも非常に大きなショックがある。平均4時間リターンは `+0.0262%` と3銘柄で最も高いが、中央値は `0.0000%` であり、平均値が外れ値の影響を受けている可能性がある。

記事での使い方:

- SOL は高ベータ銘柄として別枠で扱うべきである。
- 急落後リバウンドが見えても、MAE、MFE、スリッページ、清算リスクを見ないと危険である。
- SOL 専用ルールは過剰最適化になりやすいため、最初から記事の主役にしない方がよい。

## 5. 急落・急騰イベントの目安

Phase 2 で使う急落・急騰条件の目安は以下である。

| 銘柄 | 下位5% | 下位1% | 上位5% | 上位1% |
|---|---:|---:|---:|---:|
| BTCUSDT | `-1.8988%` | `-3.8647%` | `+1.9013%` | `+3.7063%` |
| ETHUSDT | `-2.5347%` | `-5.0589%` | `+2.5346%` | `+4.6751%` |
| SOLUSDT | `-3.7213%` | `-7.0432%` | `+3.8325%` | `+7.4639%` |

同じ「下位5%急落」でも、BTC では約 `-1.9%`、SOL では約 `-3.7%` であり、ショックの大きさが全く違う。したがって、Phase 2 では固定パーセント閾値ではなく、各銘柄自身の分布内で急落・急騰を定義するのが妥当である。

## 6. 記事用の要約

BTC、ETH、SOL はすべて暗号資産だが、4時間足リターン分布は同じではない。

BTC は3銘柄の中では最も安定しているが、それでも超過尖度は高く、極端な4時間足リターンが存在する。ETH は BTC よりボラティリティが高く、下方向への歪みが強い。SOL はさらに別物で、標準偏差は BTC の約2倍、最大下落は `-31%` を超え、平均値だけを見ると危険な高ボラ・厚いテール銘柄である。

この結果から、急落後リバウンドを検証する際には、BTC / ETH / SOL を同じ閾値で比較するのではなく、各銘柄の分布に基づいて急落を定義する必要がある。特に SOL は、反発幅が大きく見える可能性がある一方で、途中逆行や清算リスクも大きいため、Phase 4 の MAE/MFE 確認が不可欠である。

## 7. Phase 2 への接続

Phase 1 は、「急落後は買いか」を判断する段階ではなく、急落イベントを定義するための地図を作った段階である。

次の Phase 2 では、以下を確認する。

- 下位5%、下位2.5%、下位1%急落後の未来リターン
- 上位5%、上位2.5%、上位1%急騰後の未来リターン
- 4H / 8H / 12H / 24H / 48H / 72H のどこで平均回帰または継続が出るか
- BTC / ETH / SOL のどれが急落後に反発しやすいか
- 平均だけでなく、中央値、勝率、t値、件数も見る

この段階で候補が見つかった場合でも、すぐに売買ルールとは見なさない。Phase 3 のボラティリティ階層別分析、Phase 4 の次足始値エントリーと MAE/MFE、Phase 5 の年別安定性を通して、記事で主張できる材料かどうかを確認する。
