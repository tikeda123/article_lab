# **1\. 記事の中心テーマ**

記事の主役は「BTC・ETH・SOLのモーメント分析」ではなく、次の問いに置くべきです。

**BTC・ETH・SOLの急落後は本当に買いなのか。**
**それとも、Funding Rate・Open Interest・清算を見ると、買ってはいけない急落もあるのか。**

暗号資産市場では、急落の意味が一つではありません。一時的な投げ売りであれば平均回帰の候補になりますが、ロング過熱、OI積み上がり、清算連鎖の最中であれば「落ちるナイフ」を買う危険があります。

# **6\. 実験設計：価格データだけで行う基本実験**

## **6.1 実験1：BTC・ETH・SOLのリターン分布比較**

目的は、BTC・ETH・SOLを同じ暗号資産として扱わず、銘柄ごとの性格をデータで確認することです。

| 分析項目 | 確認すること |
| :---- | :---- |
| 平均・中央値 | 通常時の方向性、外れ値依存の有無。 |
| 標準偏差 | 4時間足ベースのボラティリティ比較。 |
| 歪度 | 上方向・下方向どちらのテールが強いか。 |
| 超過尖度 | ファットテールの強さ。 |
| 最大上昇・最大下落 | 実際に発生した極端値。 |
| ヒストグラム・QQプロット | 正規分布からのズレとテールの厚さ。 |

## **6.2 実験2：急落後イベントスタディ**

記事の中心実験です。急落を下位5%、2.5%、1%で定義し、その後のリターンをBTC/ETH/SOLで比較します。

| 条件 | 検証内容 |
| :---- | :---- |
| 下位5%急落後ロング | 通常の大きな急落後に反発するか。 |
| 下位2.5%急落後ロング | より強い急落後に反発が強まるか。 |
| 下位1%急落後ロング | 極端なパニック後に反発するか、それとも継続下落するか。 |
| 保有期間別比較 | 4H/12H/24H/48H/72Hのどこでエッジが出るか。 |
| 銘柄別比較 | BTC、ETH、SOLのどれが最も平均回帰しやすいか。 |

## **6.3 実験3：急騰後イベントスタディ**

急騰後の反落、またはモメンタム継続を検証します。仮想通貨ではショートスクイーズ後にさらに上がる場合もあるため、単純な逆張り前提にしないことが重要です。

| 条件 | 検証内容 |
| :---- | :---- |
| 上位5%急騰後ショート | 急騰後に反落するか。 |
| 上位2.5%急騰後ショート | 強い急騰後に反落するか、続伸するか。 |
| 上位1%急騰後ショート | ショートスクイーズ後の継続性を確認。 |

## **6.4 実験4：ボラティリティ階層別分析**

急落後の反発は、低ボラ時と高ボラ時で意味が異なります。rolling volatilityを5分位に分け、急落後リターンを比較します。

| 分類 | 解釈 |
| :---- | :---- |
| 低ボラ急落 | 一時的なノイズ、またはレンジ内の過剰反応の可能性。 |
| 中ボラ急落 | 通常の調整局面。 |
| 高ボラ急落 | 反発幅は大きい可能性があるが、MAEと清算リスクも大きい。 |

# **7\. 実験設計：仮想通貨特有データを使う拡張実験**

## **7.1 Funding Rateで急落を分類する**

最初に追加すべきデリバティブ指標はFunding Rateです。Fundingはポジションの偏りと保有コストを示すため、急落後ロングの可否を判断する重要な条件になります。

| 分類 | 条件例 | 仮説 |
| :---- | :---- | :---- |
| Funding高い \+ 急落 | Funding上位20%かつ下位5%急落 | ロング過熱の巻き戻し。逆張りは危険な可能性。 |
| Funding低い/マイナス \+ 急落 | Funding下位20%かつ下位5%急落 | ショート過熱または悲観過剰。反発しやすい可能性。 |
| Funding中立 \+ 急落 | 中央60%かつ下位5%急落 | 価格ショック単体の平均回帰を観察。 |

## **7.2 Open Interestで急落を分類する**

Open Interestは、レバレッジポジションの蓄積と解消を見るために使います。価格急変後にOIが増えているのか、減っているのかで解釈が変わります。

| 価格変化 | OI変化 | 解釈仮説 |
| :---- | :---- | :---- |
| 上昇 | OI増加 | 新規ロング流入。トレンド継続の可能性。 |
| 上昇 | OI減少 | ショートカバー。上昇一服の可能性。 |
| 下落 | OI増加 | 新規ショート増加、またはロング捕まり。下落継続リスク。 |
| 下落 | OI減少 | デレバレッジや清算後。反発余地の可能性。 |

## **7.3 清算データで「投げ売り完了」と「清算連鎖」を分ける**

清算データが取得できる場合、最も暗号資産らしい分析になります。急落を「一時的な投げ売り」と「清算連鎖の途中」に分けることができます。

| 条件 | 仮説 |
| :---- | :---- |
| 急落 \+ ロング清算急増 \+ OI減少 | 強制売りが一巡し、短期反発しやすい可能性。 |
| 急落 \+ ロング清算急増 \+ OI増加 | 新規ショートも入っており、下落継続リスク。 |
| 急騰 \+ ショート清算急増 \+ OI減少 | ショートカバー一巡で反落しやすい可能性。 |
| 急騰 \+ ショート清算急増 \+ OI増加 | 新規ロング流入で上昇継続の可能性。 |

# **8\. 評価指標**

平均リターンだけで判断しないことが重要です。仮想通貨では外れ値依存、途中逆行、コスト、Funding、清算リスクが大きく影響します。

| 指標 | 意味 | 記事での使い方 |
| :---- | :---- | :---- |
| 平均リターン | エッジ候補の大きさ | 最初の比較には使うが、単独判断は禁止。 |
| 中央値 | 外れ値依存の確認 | 平均だけ良い場合の危険を示す。 |
| 勝率 | 方向の当たりやすさ | 期待値と併用する。 |
| Profit Factor | 利益/損失の非対称性 | 実売買に近い評価として使う。 |
| MAE | 最大逆行幅 | 損切りや耐久性の確認に必須。 |
| MFE | 最大含み益 | 利確設計に使う。 |
| 最大DD | 戦略の生存性 | 最終ルールの評価で必須。 |
| 年別成績 | 再現性 | 特定年だけの偶然を排除。 |
| 信頼区間 | 統計的な不確実性 | サンプル不足や偶然を可視化。 |

# **10\. バックテストルール例**

## **ルールA：価格だけの急落後ロング**

* 条件：4時間足リターンが過去ローリング分布の下位5%以下。
* エントリー：次の4時間足始値でロング。
* 決済：24H、48H、72Hの時間決済を比較。
* 評価：平均リターン、勝率、PF、MAE、最大DD。

## **ルールB：Funding Rateフィルター付き急落後ロング**

* 条件：4時間足リターンが下位5%以下、かつFunding Rateが下位20%またはマイナス。
* 仮説：悲観過剰またはショート過熱時の急落は反発しやすい。

## **ルールC：買ってはいけない急落フィルター**

* 条件：4時間足リターンが下位5%以下、Funding Rateが上位20%、OI増加またはロング清算急増。
* 仮説：ロング過熱崩壊、または清算連鎖中の可能性があるため、急落後ロングを避ける。

## **ルールD：SOL専用高ボラ反発ルール**

* 条件：SOLUSDT、下位5%急落、vol20がQ4またはQ5、Fundingが中立以下。
* 仮説：SOLは反発幅が大きい可能性があるが、MAEとスリッページも大きい。
* 注意：SOL専用ルールは過剰最適化になりやすいため、最初から主役にしない。

# **12\. 必ず書くべき注意点**

## **12.1 全期間の分位点を売買ルールに使わない**

探索分析では全期間の下位5%を見てもよいですが、バックテストでそのまま使うと未来情報を使うことになります。実売買に近づけるには、過去365日または過去1000本などのローリング分布で閾値を決めます。

## **12.2 終値シグナル・同時終値エントリーは禁止**

4時間足の終値でシグナルを判定した場合、同じ終値でエントリーすることは実売買では再現できません。シグナル足確定後、次足始値エントリーを標準にします。

## **12.3 PerpではFundingを損益に入れる**

パーペチュアル先物では、価格損益だけでなくFundingの支払い/受取りが成績に影響します。特に24時間以上保有する検証ではFundingを無視しない方がよいです。

## **12.4 SOLはサンプル期間と流動性に注意**

SOLはBTC/ETHよりデータ期間が短く、ボラティリティも高いため、平均リターンが大きく見えてもMAE、スリッページ、清算リスクで実運用成績が悪化する可能性があります。

# **13\. 最終結論の書き方**

実験前の段階では、結果を断定しすぎない方がよいです。結論は次のような形にします。

*BTC・ETH・SOLの急落後リターンを比較すると、価格だけでも平均回帰の候補は見つかる可能性がある。*
*しかし、仮想通貨市場では急落の意味が一つではない。Funding Rateが高い状態での急落、OIが積み上がったままの急落、清算が連鎖している急落は、単なる押し目ではなく、レバレッジ解消の途中かもしれない。*
*したがって、暗号資産のクオンツ分析では、価格分布だけでなく、Funding Rate・Open Interest・清算を組み合わせて「買ってよい急落」と「買ってはいけない急落」を分ける必要がある。*
