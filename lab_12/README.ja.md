# lab_12: ポートフォリオ分散・共分散・ファットテール

English: [README.md](README.md)

このラボは、Qiita記事「[「分散したつもり」の罠 — 共分散とファットテールから考えるポートフォリオリスク](https://qiita.com/tikeda123/items/125802e6ed4468c7037e)」に対応する実験パッケージである。

小規模な人工データ実験を通じて、保有数だけでは分散効果が決まらないこと、相関が局面によって変化すること、ファットテール下で分散推定が不安定になること、低いPearson相関と深刻な共同下落が両立し得ることを確認する。

このラボは投資助言ではなく、本番運用可能なポートフォリオ構築システムでもない。記事の数値と図を再現し、リスク指標の意味と限界を確認するための教育用実験パッケージである。

## 主要結果

- 各資産の年率ボラを20%、共通相関を `rho = 0.5` とすると、銘柄数を10から100へ増やしてもポートフォリオボラは14.83%から14.21%にしか低下しない。
- レジームスイッチ実験の平均ペア相関は、全期間で0.36、市場リターン中央80%の日で-0.05、下位10%の日で0.63となる。
- 1,000日標本へ-15%の観測値を1日追加すると、推定年率ボラは4.71%から8.88%へ上昇する。
- テール依存実験では、Pearson相関とポートフォリオボラがほぼ同じ2標本でも、ポートフォリオの最悪日は-41.69%と-6.96%に分かれる。
- 実験5の2戦略は実現算術平均、標本ボラ、リスクフリー0のSharpeが一致する。それでも最大DDのピーク〜ボトム対数損失に占める最悪1日の割合は10.5%と50.8%に分かれる。

## 解釈上の注意

- 各実験は特定のメカニズムを切り出した人工データであり、実市場の予測モデルではない。
- 条件付き相関には選択バイアスがあるため、下落側だけでなく上昇側も並べて解釈する。
- 自由度 `nu = 3` のStudent-t分布は母分散が有限であり、標本標準偏差は一致推定量である。ただし正規分布より収束が遅く、不規則になる。
- 深い閾値のテール依存推定に使える観測数は少なく、安定した最適化入力として扱うべきではない。
- 実験5で一致させているのは実現算術平均であり、複利年率リターンではない。分布形状が異なるため幾何平均はずれる。
